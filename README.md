# VergeOS Documentation

The official documentation for **VergeOS** — the unified operating system for
virtualization, software-defined networking, and storage.

📖 **Read the docs:** <https://docs.verge.io>

This repository holds the source content. The published site is the best way to read it,
with full navigation and search.

## What's here

The documentation is organized by what you're trying to do:

| Section                           | What it covers                                                            |
| --------------------------------- | ------------------------------------------------------------------------- |
| **Overview**                      | Get oriented and pick a starting path.                                    |
| **Plan and deploy**               | Concepts, sizing, network design, and installation.                       |
| **Run the platform**              | Day-to-day operation — VMs, networking, storage, tenants, and the system. |
| **Automate, protect, and extend** | Automation, backup and DR, integrations, and developer tools.             |
| **Learn the platform**            | Guided, hands-on training.                                                |
| **Knowledge base**                | Troubleshooting articles, how-tos, and field guidance.                    |
| **Release notes**                 | Version history, supported releases, and the upgrade path.                |
